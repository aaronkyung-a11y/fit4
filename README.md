# 4주 시작 프로그램 — 설치와 동기화

## 1. 웹에 올리기 (GitHub Pages)
1. GitHub에 새 저장소를 만듭니다 (Public).
2. 이 폴더의 파일을 저장소 최상단에 올립니다.
   `index.html` `config.js` `sw.js` `manifest.webmanifest`
   `icon-192.png` `icon-512.png` `icon-180.png` `icon-512-maskable.png`
   (`SETUP.sql` 과 이 README는 올려도 되고 안 올려도 됩니다)
3. Settings → Pages → Source를 `main` 브랜치 `/ (root)` 로 지정합니다.
4. 1~2분 뒤 `https://<계정명>.github.io/<저장소명>/` 이 열립니다.

## 2. 폰에 설치
**아이폰** — 반드시 **사파리**로 엽니다. 하단 공유 → "홈 화면에 추가".
크롬으로 하면 설치되지 않습니다.

**안드로이드** — 크롬으로 열고 ⋮ → "앱 설치".

여기까지만 해도 앱은 완전히 작동합니다. 기록은 각자 폰에만 남습니다.

---

## 3. 두 폰 기록 맞추기 (선택)

### 3-1. Supabase 준비 (5분, 무료)
1. supabase.com 가입 → New project 생성
2. 좌측 **SQL Editor** → `SETUP.sql` 내용을 통째로 붙여넣고 Run
3. 좌측 **Settings → API** 에서 두 값을 복사
   - Project URL
   - anon public key

### 3-2. config.js 채우기
```js
window.FIT4_CONFIG = {
  SUPABASE_URL: "https://xxxxx.supabase.co",
  SUPABASE_ANON_KEY: "eyJhbGci...",
};
```
저장하고 GitHub에 다시 올립니다.
**`sw.js` 첫 줄의 `CACHE = "fit4-v0.4"` 을 `fit4-v0.4` 로 바꿔야** 폰에 반영됩니다.
버전 문자열을 안 바꾸면 옛날 캐시가 계속 뜹니다.

### 3-3. 앱에서 연결
1. 한 사람이 앱 하단 **"방 만들기"** → 16자리 코드가 나옵니다
2. 코드를 상대방에게 전달 (복사 버튼 있음)
3. 상대방은 **"코드로 참여"** 에 입력

이제 두 폰이 같은 기록을 봅니다. 자기 칸만 체크할 수 있고,
상대 칸은 읽기 전용입니다. 30초마다, 그리고 앱을 다시 열 때마다 갱신됩니다.

방을 만든 사람이 1번, 참여한 사람이 2번으로 자동 지정됩니다.
바꾸려면 하단의 "나는 [1번][2번]" 에서 누르면 됩니다.

## 4. 버전 확인

앱 맨 아래에 `v0.5 · 2026-08-31` 형태로 표시됩니다. 폰 화면의 버전이
저장소의 최신 버전과 다르면 그 옆 "업데이트 확인"을 누르면 됩니다.

코드를 고칠 때는 세 곳을 함께 올리세요.
`index.html` 상단 주석 / `APP_VERSION` 상수 / `sw.js` 의 `CACHE`

## 5. 알아둘 점

**보안** — 방 코드는 16자리 무작위 문자열입니다. 코드를 모르면 기록에
접근할 수 없고 전체 목록도 뽑을 수 없습니다. 반대로 코드를 아는 사람은
누구나 읽고 쓸 수 있습니다. 운동 체크 용도로는 충분하지만 민감한 정보는
넣지 마세요.

**anon 키** — 공개돼도 되는 키입니다. 다만 `SETUP.sql` 을 먼저 실행해야
테이블 직접 접근이 막힙니다. SQL을 건너뛰면 안 됩니다.

**오프라인** — 서버에 못 닿아도 체크는 폰에 저장됩니다. 연결되면 자동으로
올라갑니다. 화면 하단에 "연결 실패"로 표시됩니다.

**동시 편집** — 두 사람이 같은 순간에 체크해도 서로의 기록을 덮어쓰지
않습니다. 올리기 직전에 서버 값을 다시 받아 합칩니다. 다만 완전한
트랜잭션은 아니라서, 정확히 같은 초에 둘 다 누르면 한쪽이 밀릴 수
있습니다. 다음 갱신 때 복구됩니다.

**시크릿 모드** — 사파리/크롬 시크릿 창에서는 저장되지 않습니다.

**config.js 를 비워두면** 동기화 기능이 화면에서 사라지고 로컬 앱으로만
동작합니다. 나중에 채워도 됩니다.
